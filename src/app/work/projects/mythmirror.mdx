<Pt>
  ## O Desafio

A MythMirror é uma startup EdTech com a audaciosa missão de redefinir a identidade digital, unindo Educação, Finanças e Lazer por meio da gamificação. 

O desafio era construir não apenas um site, mas uma **experiência imersiva** que servisse como a porta de entrada perfeita para o ecossistema. Precisávamos de:

- **Estética Futurista:** Um tema cinematográfico em Dark Mode profundo, integrando Glassmorphism e elementos Neon.
- **Imersão sem Perda de Performance:** Utilização de modelos 3D interativos (como DNA e Networks) que funcionassem fluidamente, inclusive em dispositivos móveis.
- **Conversão Integrada:** Formulários B2B e B2C integrados de forma transparente, sem a necessidade de uma infraestrutura de backend complexa.
</Pt>

<En>
  ## The Challenge

MythMirror is an EdTech startup with the bold mission of redefining digital identity, merging Education, Finance, and Leisure through gamification.

The challenge was to build not just a website, but an **immersive experience** that served as the perfect gateway to the ecosystem. We needed:

- **Futuristic Aesthetics:** A cinematic deep Dark Mode theme, integrating Glassmorphism and Neon elements.
- **Immersion without Performance Loss:** Interactive 3D models (like DNA and Networks) running smoothly, even on mobile devices.
- **Integrated Conversion:** B2B and B2C forms integrated seamlessly without the need for complex backend infrastructure.
</En>

Isso permitiu conectar nossos formulários de captação de leads diretamente à API do Brevo rodando a lógica exclusivamente no lado do servidor, protegendo chaves de API e melhorando o tempo de resposta.

<En>
  ## Technical Highlight: Server Actions & Brevo
  
  To keep the architecture lean and secure (Zero Backend), we utilized Next.js 14 **Server Actions**. This allowed us to connect our lead capture forms directly to the Brevo API, running the logic exclusively on the server side, protecting API keys, and improving response times.

<Pt>
  ## Resultado e Aprendizados

O projeto resultou em uma landing page de altíssima fidelidade visual. A combinação de **Framer Motion** para o DOM 2D com o **React Three Fiber** no Canvas 3D criou uma narrativa de rolagem (scroll-telling) envolvente. 

O maior desafio técnico foi sincronizar os contextos de I18n (Context API) com os componentes renderizados dentro do Canvas 3D, exigindo pontes de estado cuidadosas para garantir que a troca de idioma (PT/EN) refletisse instantaneamente nos textos flutuantes dos modelos tridimensionais.
</Pt>

<En>
  ## Results and Key Learnings

The project resulted in a visual powerhouse of a landing page. Combining **Framer Motion** for the 2D DOM with **React Three Fiber** on the 3D Canvas created an engaging scroll-telling narrative.

The biggest technical challenge was synchronizing the I18n contexts (Context API) with the components rendered inside the 3D Canvas, requiring careful state bridges to ensure language switching (PT/EN) instantly reflected on the floating text of the three-dimensional models.
</En>
