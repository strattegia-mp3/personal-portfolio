<Pt>
  ## O Desafio

O mercado está cheio de agregadores de links genéricos que falham em transmitir a percepção de alto valor de um profissional ou marca. 

O objetivo com o **stratt-links** foi construir uma *Micro Landing Page* premium e minimalista. Os pilares do projeto foram:
- **Separação Rigorosa (Data Decoupling):** Permitir que o usuário atualize links, textos e imagens em menos de 2 minutos sem tocar em nenhum componente visual (JSX).
- **UX Impecável:** Transições com física de molas (*springs*) e efeitos 3D que elevam a percepção de valor sem causar fadiga visual.
- **Design Semântico:** Eliminar a poluição de classes `dark:` no código, utilizando o novo motor do Tailwind CSS v4 para gerenciar o suporte a *Light/Dark mode* nativamente no CSS.
</Pt>

<En>
  ## The Challenge

The market is flooded with generic link aggregators that fail to convey the high-value perception of a professional or brand.

The goal with **stratt-links** was to build a premium, minimalist *Micro Landing Page*. The project pillars were:
- **Strict Data Decoupling:** Allowing users to update links, texts, and images in under 2 minutes without touching any visual components (JSX).
- **Flawless UX:** Transitions with spring physics and 3D effects that elevate perceived value without causing visual fatigue.
- **Semantic Design:** Eliminating the pollution of `dark:` classes in the code by using the new Tailwind CSS v4 engine to manage *Light/Dark mode* support natively via CSS.
</En>

<Pt>
  ## Resultado e Aprendizados

O projeto resultou em uma aplicação que se comporta como um *App Nativo*, com PWA (Progressive Web App) configurado e cores de manifesto ajustadas para transições suaves em dispositivos móveis. A atenção à acessibilidade garantiu que as cores tivessem o contraste cirurgicamente calculado para ambos os temas.

O grande aprendizado foi equilibrar o uso de **Framer Motion** para o efeito interativo de *tilt 3D* nos links e o radar pulsante do botão de WhatsApp, mantendo a responsividade impecável e notas máximas de performance na Vercel.
</Pt>

<En>
  ## Results and Key Learnings

The project resulted in an application that behaves like a *Native App*, with PWA (Progressive Web App) configured and manifest colors adjusted for smooth transitions on mobile devices. The attention to accessibility ensured that colors had surgically calculated contrast for both themes.

The main takeaway was balancing the use of **Framer Motion** for the interactive 3D tilt effect on the links and the pulsing radar on the WhatsApp button, while maintaining flawless responsiveness and top performance scores on Vercel.
</En>
